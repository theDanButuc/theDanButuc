##### 🧠 What I Do

- **Product Engineering with AI** — Define scope, design the architecture, direct implementation with Claude Code, review critically, ship and operate. Spec-driven, end-to-end ownership.
- **AI & Workflow Automation** — Build intelligent n8n workflows, API integrations, and AI-assisted automation for business processes — including locally hosted LLMs where data can't leave the client's infrastructure
- **Web Design & Development** — Design and develop responsive websites using WordPress, Elementor, React, and modern web technologies
- **Cloud Infrastructure** — Design, deploy, and manage scalable cloud solutions on AWS, Azure with Terraform & Infrastructure as Code
- **SVG & Animation** — Build custom SVG components, scroll-triggered animations, and design system tooling
- **Native App Development** — Build production-grade macOS, Windows and Android applications using Swift/SwiftUI, C#, Kotlin, and Jetpack Compose — from menu bar utilities to full-featured hardware controllers
- **Creative Automation** — Photoshop automation, image processing pipelines, and design workflow optimization
